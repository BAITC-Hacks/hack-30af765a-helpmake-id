# Структура frontend Akim AI

Frontend — React + TypeScript + Vite. Он показывает данные, полученные из Simulation API, управляет выбором мер и отправляет сценарий на сервер. Числовые результаты не рассчитываются в браузере.

```text
frontend/
├── index.html
├── .env.example
├── src/
│   ├── main.tsx             # запуск приложения
│   ├── App.tsx              # карта, каталог решений, результат
│   ├── styles.css           # адаптивные стили
│   ├── api/client.ts        # GET данных и POST сценария
│   └── data/model.ts        # типы ответа и преобразование данных для UI
└── package.json
```

Источник истины для стоимости мер, их эффектов, индикаторов, ограничений и Score — `backend/data/simulation.json` вместе с `backend/app/simulation_engine.py`. В `model.ts` остаются только типы, русские подписи интерфейса и приблизительные точки районов для карты.

Базовый URL API задаётся `VITE_API_URL`, по умолчанию `http://127.0.0.1:8000/api/v1`. Переменные `VITE_*` попадают в клиентскую сборку, поэтому секреты и ключи провайдеров там хранить нельзя.

Интерфейс различает загрузку, ошибку подключения, исходные данные и результат серверного расчёта. При изменении выбранных мер или района применения старый результат сбрасывается. Backend повторно проверяет все ограничения перед расчётом.
