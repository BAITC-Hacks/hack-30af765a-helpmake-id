# Структура frontend Akim AI

Frontend — React + TypeScript + Vite. Он показывает данные, полученные из Simulation API, управляет выбором мер и отправляет сценарий на сервер. Числовые результаты не рассчитываются в браузере.

```text
frontend/
├── index.html
├── .env.example
├── src/
│   ├── main.tsx             # запуск приложения
│   ├── App.tsx              # карта, каталог решений, результат
│   ├── styles.css           # адаптивные стили
│   ├── api/client.ts        # GET данных и POST сценария
│   └── data/model.ts        # типы ответа и преобразование данных для UI
└── package.json
```

Источник истины для мер, индикаторов, ограничений и Score — API в `backend/api/`. Каталог загружается через `GET /api/v1/data`, сценарий отправляется в `POST /api/v1/simulate`, объяснение запрашивается через `POST /api/v1/advisor/explain`. В `model.ts` находятся типы, подписи интерфейса, адаптер ответа и приблизительные точки районов для карты.

Базовый URL API задаётся `VITE_API_URL`, по умолчанию `/api/v1`. В локальной разработке Vite перенаправляет `/api` на `http://127.0.0.1:8000`; для другого адреса API задайте `VITE_API_URL` при сборке. Переменные `VITE_*` попадают в клиентскую сборку, поэтому секреты и ключи провайдеров там хранить нельзя.

Интерфейс различает загрузку, ошибку подключения, исходные данные и результат серверного расчёта. При изменении выбранных мер или района применения старый результат сбрасывается. Backend повторно проверяет все ограничения перед расчётом. Если AI Advisor недоступен, числовой результат и разбор по данным остаются видимыми.
